# Nidhi Farms

Static website for Nidhi Farms, a sourcing and wholesale supply company in Andhra Pradesh, India. The business buys herbs and other ethical products from vetted sellers and supplies bulk and export buyers.

Live site: https://nidhi-bhai.github.io/nidhi-farms-3d-integrated/

The site is plain HTML, CSS and JavaScript. Pushing to `main` runs `.github/workflows/pages.yml`, which publishes the repository root with GitHub Pages.

Pages is not publishing yet. In the repository, open **Settings → Pages → Build and deployment** and set **Source** to **GitHub Actions**. Then re-run the **Deploy GitHub Pages** workflow on `main`.
